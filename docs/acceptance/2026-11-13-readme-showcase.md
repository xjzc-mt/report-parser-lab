# README 演示案例复检记录

日期：2026-11-13

范围：`README.md`、`docs/examples/showcase/`、`docs/images/showcase/` 与文档索引。

## 复检内容

- 使用三份虚构 PDF、`requirements.csv` 和固定本地演示连接完成线上验证，得到 71 行提取结果并导出 Excel。
- 使用 `results-v1.csv` 与 `ground-truth.csv` 完成模型结果验收，覆盖 72 个测试项、75 条关联明细，检查报告视角、指标类型视角和用水量明细。
- 导入 `prompt-assets.csv` 创建 12 个 Prompt 资产，再导入 `prompt-assets-v2.csv` 为 `WATER_TOTAL` 增加版本，确认版本历史与修订规则可见。
- 读取三份报告 PDF 的页码、表格和中文字体，确认报告页码与 `ground-truth.csv` 中的物理页码一致。
- 检查 README 中的相对链接和四张 JPG 展示图均存在。

## 样例统计

验收阈值为 70。v1 与 v2 预测结果均为人工构造，用于展示问题分类和复验流程。

| 统计项 | v1 | v2 |
| --- | ---: | ---: |
| 测试项 | 72 | 72 |
| 预测输出行 | 71 | 72 |
| 严格通过 | 42（58.3%） | 65（90.3%） |
| 漏提测试项 | 8 | 2 |
| 含重复输出的测试项 | 4 | 1 |
| 标准答案之外的输出 | 3 | 1 |

用水量案例来自晨川科技报告第 1 页。2025 年总用水量标准答案为 800 立方米，取水量为 960 立方米。v1 取到了取水量，v2 的修订规则保留了总用水量口径。

## 未覆盖项

本次 README 演示使用本地固定样例服务，没有调用真实模型，也没有将真实报告或密钥写入仓库。真实模型的协议、附件能力、费用和结果需要在目标环境单独复核。
