# 完整演示案例

本目录包含三家虚构企业的报告、指标需求、人工标准答案和两版人工构造的预测结果。用于体验报告提取、结果验收与 Prompt 迭代流程。

**公司、报告、数字和预测结果均为演示数据。两版结果是预先构造的，不能作为真实模型效果、Prompt 优化收益或通用准确率的证据。** 验收统计由项目现用的关联与评分规则计算。

## 数据范围

- 三份报告，每份四页，物理页码从 1 开始。
- 每份报告披露 2024 年和 2025 年的 12 项指标，共 72 个标准答案测试项。
- 指标包含文字型、数值型、货币型和强度型。
- 演示覆盖数值错误、统计口径混淆、漏提、重复提取、单位错误和标准答案之外的额外输出。

| 文件 | 用途 |
| --- | --- |
| [晨川科技报告](reports/晨川科技_2025可持续发展报告.pdf) | 科技企业虚构报告，包含用水量核心案例 |
| [远岚制造报告](reports/远岚制造_2025可持续发展报告.pdf) | 制造企业虚构报告 |
| [海岑能源报告](reports/海岑能源_2025可持续发展报告.pdf) | 能源企业虚构报告 |
| [requirements.csv](requirements.csv) | 12 项提取需求，含指标类型、定义、用户提示词、系统提示词与输出结构 |
| [ground-truth.csv](ground-truth.csv) | 72 项人工标准答案，作为验收基准 |
| [results-v1.csv](results-v1.csv) | 初版构造预测，包含多类错误 |
| [results-v2.csv](results-v2.csv) | 复验版构造预测，保留少量错误供检查 |
| [prompt-assets.csv](prompt-assets.csv) | 可导入资产库的 12 个初版指标 Prompt |
| [prompt-assets-v2.csv](prompt-assets-v2.csv) | 总用水量 Prompt 更新，其余 11 项保持相同 |
| [summary.json](summary.json) | 使用当前关联与分析代码计算的汇总统计，阈值为 70 |

提取需求与两版 Prompt 资产均采用通用输出契约，只约束字段和取值来源，不预填指标答案、公司、年份或数值。

CSV 使用带 BOM 的 UTF-8 编码，直接上传即可。`report_name` 为文件名去掉 `.pdf` 后的名称。年份在预测表使用 `year`，在标准答案表使用 `data_year`。

## 完成一次本地验收

1. 按[快速开始](../../../README.md#快速开始)启动项目，打开「模型结果验收」。
2. 在模型结果一侧上传 `results-v1.csv`，在标准答案一侧上传 `ground-truth.csv`。
3. 使用默认映射 `report_name`、`indicator_code`、`year ↔ data_year`，点击「开始关联分析」。
4. 按报告或指标查看错值、漏提、重复和额外输出，下载关联对比工作簿。
5. 将模型结果替换为 `results-v2.csv`，重新分析，核对下表。

| 当前验收口径 | 初版构造预测 | 复验版构造预测 |
| --- | --- | --- |
| 测试项 | 72 | 72 |
| 预测输出行 | 71 | 72 |
| 严格通过 | 42 / 72（58.3%） | 65 / 72（90.3%） |
| 宽松通过 | 46 / 72（63.9%） | 66 / 72（91.7%） |
| 漏提测试项 | 8 | 2 |
| 含重复输出的测试项 | 4 | 1 |
| 标准答案之外的输出 | 3 | 1 |

严格通过要求该测试项只有一条输出且相似度达到阈值。宽松通过允许同一测试项存在多条输出，只要其中一条达标。额外输出在页面中可能标记为“幻觉”，本案例的额外输出是刻意构造的未标注指标。

## 对照用水量案例

打开晨川科技报告第 1 页。报告同时列出总用水量和取水量。

| 字段 | 2024 年 | 2025 年 |
| --- | --- | --- |
| 总用水量 | 740 立方米 | 800 立方米 |
| 取水量 | 888 立方米 | 960 立方米 |

初版构造预测把 2025 年总用水量写成 `960`，复验版构造预测写成 `800`。两版均关联到同一项人工答案，便于观察数值差异及对应页码。

初版用户提示词：

```text
提取报告中 2024 年和 2025 年的总用水量，保留数值、单位和 PDF 物理页码。
```

调整后的用户提示词：

```text
提取报告中 2024 年和 2025 年的总用水量。
优先查找第 1 页“环境资源与排放”表中“总用水量”行，分别读取对应年份列。
“取水量”与“总用水量”口径分别核对，不得替代。
保留原始数值与单位，不做换算。
每个年份只返回一条结果，并填写 PDF 物理页码。
```

要体验资产管理，在 Prompt 资产库导入 `prompt-assets.csv`，再导入 `prompt-assets-v2.csv`。首次导入创建 12 个资产，第二次导入只为总用水量增加一个版本。

## 用自己的模型试跑

配置自己的模型后，可在「线上验证」上传三份 PDF 和 `requirements.csv`，或在「Prompt快速迭代」中选择资产并上传对应报告。下载模型实际输出后，根据[数据格式说明](../../getting-started.md#接入自己的数据)整理关联字段，再与 `ground-truth.csv` 验收。

真实模型输出由所选模型、协议与参数决定，应与本目录中的人工构造预测分别保存。本案例中的“第 1 页”定位针对这三份虚构报告，迁移到其他报告时应调整。
